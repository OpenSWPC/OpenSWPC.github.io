# Getting Started
OpenSWPC is a software package for simulating seismic wave propagation in complex Earth structures with a relatively simple set of parameters.
You can try out the compilation and execution of OpenSWPC using a Google Colaboratory [Notebook](https://colab.research.google.com/gist/tktmyd/2c1e98d1b0744e80f111402b4bfe6975/OpenSWPC_trial.en.ipynb). In this Notebook, you will download and compile OpenSWPC in the cloud, run a parallel numerical simulation of two-dimensional P-SV wave propagation in a vertical cross section, and visualize the results by creating a snapshot movie of seismic wave propagation, such as the one shown below, as well as a record section of seismic velocity waveforms at the surface.
Anyone can view the Notebook, but a Google account is required to run it yourself.
