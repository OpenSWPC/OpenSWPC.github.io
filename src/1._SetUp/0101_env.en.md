# System requirements

Executing `OpenSWPC` requires a Fortran compiler that can handle the Fortran 2018 standard and an MPI library. 
The program can be run on a single CPU or CPU core without parallelization; however, the MPI library is still required.
In addition, the `NetCDF` library, compiled by the same Fortran compiler, is required to use the direct input/output of the `NetCDF`-formatted files.
